共有ローカルモデル（Silero VAD＋SenseVoice）を、ボイスストーンに加えてヒーローの変身ワード・NGワードの認識にも使用するようにしました。

- PC参加者は各自の端末、Web・モバイル参加者の分はPCホストが認識します。同じ話者の変身・NGワードは認識処理を共有し、古い要求や結果は破棄します。
- タヌキ丼未検出時はモデルを起動しません。モデル未準備・設定Offの場合は従来の軽量認識を使用します。音声認識APIへの音声送信やキー登録は不要です。
- 詳細設定の音声認識カードの配置・トグル・説明文・ボタンの折り返しを改善しました。Visual C++ v14 Redistributable（x64）が不足している場合は公式ダウンロードページへ案内します。
- 問い合わせの確認チェックを送信ボタンの上へ移動しました。
- Tauri版の更新ボタン、ユーザーBAN管理、問い合わせ、デバッグ認証を通常版に揃え、定期更新でスクロール位置が戻る問題を修正しました。
- .NET版のボイスエフェクト・ロビースライダー・詳細設定・問い合わせ画面を調整し、入力文字が欠ける問題とデバッグ版で認証設定がない場合に正しいパスワードでも拒否される問題を修正しました。

通常版・Lite版は3.2.70、Tauri版は3.2.70-tauri-beta.1、.NET版は3.2.70-net-beta.1、Web・Android・iOS版は3.68です。タヌキ丼β24と組み合わせてください。

共有モデル導入済みの場合は再導入不要です。未導入の場合は詳細設定から[共通インストーラー](https://github.com/kuretoshi/TanukiBCL/releases/download/v3.2.69/TanukiBCL-SharedSpeech-Setup-2.0.2.1.exe)を利用してください。

自動テスト・合成音声による認識・設定画面の描画を確認しています。物理マイクと多人数の実試合は未確認です。
