# Tauri版のモデル読み込みと選択肢表示の修正

2026-11-19。3.2.66-tauri-beta.3のローカル修正版。公開リリースのバージョンと配布物は変更しない。

TauriのWindowsリソースディレクトリーは実行ファイルのcanonicalizeを経由するため、`\\?\C:\...`形式になる。配布済みVosk 0.3.45は同じモデルでも通常のドライブ表記では読み込める一方、この接頭辞があると読み込みに失敗する。インストール済みモデルと配布済み実行ファイルの`--voice-speech-probe`で、通常表記の成功とverbatim表記の失敗を再現した。

モデルを開く直前にドライブ／UNCのverbatim表記を通常表記へ戻す共通処理を追加し、実際の認識ワーカーと検証用プローブの両方で使う。DLLのWindows用ワイド文字読み込みと、リソースの配置は維持する。モデルや依存関係の追加コピーは不要。

プルダウンには`select`のdark color-schemeに加え、`option`と`optgroup`の背景色・文字色を指定する。WebView2のネイティブポップアップで背景と文字の色が合わない状態を防ぐ。

回帰確認は音声認識のRust単体テストとRust UIテスト、および`node scripts/test-native-speech-path.mjs <実行ファイル> <既存のrust-speechディレクトリー>`で行う。後者は通常／verbatim表記の両方で実モデルを開き、デコーダーへ無音を渡す。マイクとスピーカーにはアクセスしない。読み込みテストは人間の発声による認識精度の確認を含まない。

## ロビー退出時の読み取りエラー

ネットワーク状態がNotJoinedへ戻った後もプレイヤー数が残っていると、通常なら読む必要のないプレイヤー一覧が空になり、「ゲームのプレイヤー構造を読み取れません」が発生していた。NotJoinedとInnerNetClientの消失では、会議やプレイヤー一覧等に触れる前にメニュースナップショットへ戻す。前回状態、色キャッシュ、明るさを更新し、再入室のための猶予状態を戻す。ゲーム終了・再接続時には読み取りエラーと連続失敗数も消去する。

回帰テストはテストプロセス内に確保したメモリを、製品と同じReadProcessMemory経由で読む。退出後に人数だけ残る場合、一覧が既に破棄された場合、InnerNetClient自体が消える場合でメニューに戻り、実際のロビー状態でプレイヤーが壊れている場合はエラーを維持することを確認する。ゲームプロセスへの書き込み・注入は行わない。
