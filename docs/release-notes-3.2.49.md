# タヌキのベタクル 3.2.49

- タヌキ丼0.1.0-β17の、プレイヤーごとの任意の変身ワードと読み方に対応しました。従来の「変身」も引き続き使用できます。
- PCは各自のマイクを認識し、ホストはWeb・モバイル参加者の音声を追加で認識します。日本語認識は端末内で動作します。
- Ko-fi／GitHub Sponsorsの支援先選択（3.2.48で追加）を引き続き利用できます。
- Windows x64の通常版とLite版を配布します。.NET版3.2.49-net-beta.1、Web・モバイル版3.41、アドオン0.1.0-β17と合わせて更新してください。

複数端末での任意ワードの実音声・新しいNGワード入力方式の通し確認は未検証です。
