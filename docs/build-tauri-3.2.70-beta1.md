# タヌキのベタクル Tauri 3.2.70 ベータ1

- 共有モデル（Silero VAD＋SenseVoice）を変身・NGワード・ボイスストーンに共通で使用します。PCは各自、Web・モバイル分はPCホストが認識します。
- 詳細設定の音声認識カード、更新ボタン、問い合わせ、ユーザーBAN管理を通常版に揃えました。
- デバッグ認証の再試行・エラー表示と、定期更新でスクロール位置が戻る問題を修正しました。
- タヌキ丼未検出時はモデルを起動しません。Visual C++ v14 Redistributable（x64）が不足している場合は公式ページを案内します。

基準ソースは通常版v3.2.70、4c01d7d9c2b772b48ee5fa40a8102149fbe26e81です。共有モデル導入済みの場合は再導入不要です。Web・モバイル3.68、タヌキ丼β24に対応します。

既存のCargoキャッシュとリソースを再利用し、npm exec -- tauri buildでインストーラーを生成します。node scripts/verify-tauri-installer.mjsで内容・チェックサム・版番号を検証します。物理マイクと多人数の実試合は未確認です。
