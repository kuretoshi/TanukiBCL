# タヌキのベタクル 3.2.56

- NoSの役職取得時にゲームプロセス全体を複製する処理を減らし、定期取得の負荷を軽減しました。
- タヌキ丼を検出した場合だけ、役職状態の読み取り、声量送信、録音・残響、音声認識を起動するようにしました。検出解除時には停止し、再検出やマイク切替にも追従します。
- 録音が不要な間は音声コールバックを停止し、NoS衣装画像の一覧と画像キャッシュの重複処理を削減しました。
- 通常版・Lite版ともに対応しています。.NET版3.2.56-net-beta.1、Web・モバイル版3.47も同時更新します。

Windows x64版です。実ゲームで報告されたフリーズの解消確認は継続中です。
