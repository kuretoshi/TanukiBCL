# 3.2.67への統合待ち

2026-11-21。ユーザーの全版3.2.67へ揃える方針に合わせ、準備していた3.2.66-tauri-beta.5の公開とビルドを取りやめた。ベータ5の配布物は公開していない。

現在の作業ディレクトリーに次の修正を保持している。

- `src-tauri/src/native/reader_startup.rs` と `native/mod.rs`：ゲーム起動時、初回正常読み取り前の既知のメモリ・パレット・DLL準備待ちだけを最大120秒待つ。同一プロセスの再試行で期限を延ばさず、正常読み取り後の障害やアクセス権・オフセット・シグネチャの異常は表示する。
- `src-tauri/src/native/reader.rs`：実際のReadProcessMemoryで初期化前の読み取り失敗→準備完了→メニュースナップショットを検証する回帰テスト。
- `src-tauri/rust-ui/assets/app.css` と `rust-ui/src/views.rs`：メニュー・プレイヤー名・コードの1行表示、長い名前の省略と全文ツールチップ。
- `src-tauri/src/voice/speech.rs`：NoSアドオンのチャットから共有された、期限更新で認識器を作り直さない修正。要求番号・対象・ルールで認識器を更新し、同じ要求の期限は継続反映する。

統合状態でRustテスト132件が通過した。音声の実ワーカー統合テスト1件は共有元で、期限一定・±1ms変動の両方で同じ合成日本語音声から認識結果が返ることを確認済み。Rust/WASM UIの280×390検証は `validation-tauri-startup-layout-3.2.66-beta5.json` に記録している。

全版共通のボイスストーン不具合はNoS側のRPCからprivateなPreview/Retry/Cancelを呼んでいたことで、共有元の実ゲームではinternal化後、UDPで確認→再録音→設置、TCPで確認→キャンセルまで成功した。公開タグv3.2.67の作成と通常版・Lite版・.NET版・アドオンの公開は共有元のチャットが担当する。

ベータ5は検証作業用の仮番号として使用した。現在のCargo/Tauri設定は3.2.67-tauri-beta.1へ更新済み。通常版の対応ソースb54e7bf56c467e1d1f29610163566e4172cf247aが確定し、共有137ファイルに変更がないことを照合してrelease-baseとpackage.jsonを3.2.67へ更新した。公開は共有元のタグ作成・全版リリース準備に合わせる。3.2.66-tauri-beta.4までの配布物は保持している。追加のプロジェクトコピー、モデル複製、ポータブル用リソース複製は行っていない。
