# タヌキのベタクル 3.2.47

- タヌキ丼0.1.0-β16の「スーパーヒーロー」「イーヴィルヒーロー」「NGワード」に対応しました。
- 「変身」とNGワードの日本語音声認識を追加しました。PC通常版・Lite版・.NET版は各自のマイクを自分の端末で認識し、ホストはWeb・モバイル参加者の声だけを追加で認識します。外部の音声認識サービスは使用しません。
- ヒーローの変身衣装を、変装によるボイスエフェクトの対象から除外しました。他の能力による音声妨害は引き続き適用します。
- Windows x64の通常版とLite版を配布します。Web・モバイル版3.39、.NET版3.2.47-net-beta.1およびアドオン0.1.0-β16と合わせて更新してください。

音声認識の取りこぼし・誤認識は発生し得ます。複数端末での実音声と大人数時の負荷は、引き続き確認が必要です。
