# Tauri 3.2.66 ベータ5のビルド

Electron v3.2.66を基準とするWindows x64版です。ベータ4までの修正を維持します。

- 初回の正常読み取り前に限り、GameAssembly・パレット・ゲームメモリの初期化待ちを最大120秒待機表示にします。同一プロセスへの再試行で期限を延ばさず、ゲーム終了・再起動時に状態を戻します。
- アクセス権・オフセット・シグネチャのエラー、初回成功後の読み取りエラーは引き続き表示します。
- 主画面上部の幅制限を見直し、日本語のメニュー表示、プレイヤー名、ロビーコードを折り返しません。長い名前は1行で省略し、ツールチップで全文を確認できます。
- ボイスストーン等の音声認識器は、期限通知の微小な更新では初期化し直さず、同じ要求の発声を保持します。要求番号・対象・ルールが変わる場合は認識器を更新します。

既存の依存・モデル・ビルドキャッシュを再利用します。配布物は新しいベータ番号のNSISインストーラーとSHA-256だけを生成し、ポータブル用リソースは複製しません。

```powershell
npm run verify:tauri-base
cargo test --manifest-path src-tauri/Cargo.toml --workspace --bins --lib
npm exec -- tauri build
# 生成されたベータ5のNSISインストーラーをdist-tauriの配布名へ配置し、SHA-256を添付する。
node scripts/verify-tauri-installer.mjs
```

回帰テストは検証プロセス内のメモリを製品と同じReadProcessMemoryで読み、起動時の読み取り失敗→パレットの準備完了→メニュー取得を確認します。ゲームプロセスへの書き込みは行いません。

2026-11-21のRustテストは本体114件、CLR補助2件、Rust UI16件の計132件が通過しました。起動猶予の期限、同一プロセスでの再試行、ゲーム終了・再起動、初期化後のエラー維持も確認しています。音声認識の実ワーカーでも、既存の日本語合成音声を使い、期限一定と±1ms更新の両方で結果が返る統合テスト1件が通過しています。

ビルドしたRust/WASM UIを280×390のChromium上で確認し、「メニュー」が幅122px・高さ46pxの1行になり、通常名と長い日本語名も高さ29pxの1行に収まること、長い名前の省略・全文ツールチップ・横方向のはみ出し防止を確認しました。実ゲームの起動直後と物理マイクによる通話は未検証です。
