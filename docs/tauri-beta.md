# タヌキのベタクル Tauri 3.2.63 ベータ1

3.2.63-tauri-beta.1では、グラトニーに飲み込まれた人の声を「聞こえない」にした際、グラトニー本人への音声を維持し、周囲への音漏れを抑えるよう修正しました。NoSの音声位置を常に使用し、飲み込み状態はUchuAddonの専用データで判断します。Rust単体テスト86件と音声ルール16,922ケースが通過しました。実ゲームでの複数人通話は未確認です。

以下の移行・実機検証結果は、特記のない限り3.2.62のβ8／β9時点です。

**3.2.63-tauri-beta.1**。公開版v3.2.63（コミット74dfdea143fe1c87baa81cb7cb3c7e25cba7dfe8）を基準としたWindows x64版です。Electron版のソース・設定・配布物は保持しています。別のアプリID・インストール先・設定フォルダーを使い、両方をインストールできます。同じゲームでの同時通話は避け、比較するときは片方ずつ起動してください。

β9ではElectron版のUIに合わせ、主画面280×390、設定750×630、起動ボタン、フッター、設定カテゴリとカード、試合画面のプレイヤー配置などをRustで復元しました。元のSVG・フォント・配置計算を再利用しています。標準HTMLの選択欄やスライダーなどに描画差があり、全画面のピクセル一致を保証するものではありません。デバッグ・履歴・各Modの全状態も追加の実画面確認が必要です。

比較用ページで空の見た目データへの再取得が連鎖する問題を修正し、空応答・エラーとも60秒の再試行間隔を設けました。13人の模擬試合で90秒の確認を実施しています。以前のTauri版で報告された13GB使用と同じ原因かは未確定です。以下のElectron／.NETとの比較結果はβ8の測定値であり、β9の再測定結果ではありません。

## 起動

配布フォルダー内の `TanukiBCL-Tauri-Beta.exe` を起動します。画面、ゲーム読み取り、通話、設定などのアプリ処理はRustです。画面はRustをWebAssemblyにコンパイルしてWebView2に表示します。wasm-bindgenとTauriの生成ブリッジはJavaScriptですが、React／TypeScriptのアプリ処理は実行しません。

画面を閉じる／最小化すると、そのWebViewを解放して通話を続けます。トレイから画面を開き直せます。終了はトレイの「終了」を使います。オーバーレイや別の設定画面を開いている場合、そのWebViewは残ります。

- `Start-Native-Voice.cmd`：通常起動。
- `Start-Native-Voice-Background.cmd`：画面を作らずバックグラウンドで起動。
- `--compact`：従来の410×650の枠付きウィンドウでRust UIを表示。

インストーラーは `TanukiBCL-Tauri-Beta-Setup-3.2.63-tauri-beta.1.exe` です。Electron用のセットアップを上書きしません。実行ファイル単体では同梱リソースが不足するため、ポータブル版はフォルダー全体を使ってください。

## Rust実装の範囲

- UI：メイン画面、37言語、プレイヤーの音量・ミュート・ラジオ、12分類の設定、音声テスト、マイクメーター、役職エフェクト、ろくろ首、カスタム起動、公開ロビー、デバッグ、問い合わせ、オーバーレイ、NoS／SNRの衣装表示。
- ゲーム：Vanilla、NoS／SNR／TOH4Eのプロセス・メモリ読み取り、CoreCLRメタデータ解析、役職・衣装・会議情報、SNRアニメーション監視。従来のC#製補助ツールをRust製x86／x64補助ツールに置換。
- 音声：CPALデバイス入出力、Opus、WebRTC、シグナリング、AEC／ノイズ抑制／自動音量、ゲート、距離・壁・ドア・視界・カメラ・会議・ラジオ判定、エフェクト、NoS録音・アドオン・リモートマイク、OBS／モバイル通信、日本語Vosk音声認識。
- アプリ：ウィンドウ・設定・IPC・キー監視・トレイ、Steam／Epic／MS Store／カスタム起動、最前面表示・GPU設定、認証・問い合わせ・管理用通信、ログ、Tauriベータ専用の更新確認・検証付きインストーラー取得。

通常の配布物にNodeランタイム、React、C#製アプリ補助ツールは含みません。既存のElectronソースと比較用コード、C#テスト用比較対象は開発用ディレクトリに保持しています。Opus／Vosk／CoreCLR DACなど第三者のネイティブ実装と、OSのWebView2は使用します。日本語音声認識モデルは必要な間だけ読み込みます。役職用PCM録音はメモリ内で扱います。

更新対象は公式リポジトリの新しいTauriベータ用セットアップだけです。サイズ・SHA256・PE形式を検証し、利用者が「インストーラーを起動」を選んだときに実行します。Electronの更新は別です。GPU設定変更はアプリの再起動後に反映します。

## 検証と制限

公開版コア127ファイルをハッシュ照合。Rustの単体テスト101件（ネイティブ84、CLR2、UI15）が通過しています。UIには公開版の設定項目56件と、元のプレイヤー配置計算1,984ケースを照合するテストがあります。β8の配布用実行ファイルでは、通話ルール16,874件、Modデコード220件、公開版AudioWorkletとのピッチ処理比較4件、双方向通話15シナリオを検証しました。β9の変更はUIとウィンドウ寸法に限定し、配布物での接続確認も行っています。

Rust CLR補助ツールの配布バイナリは、x86／x64のSNR・NoS・TOHフィクスチャーで旧C#出力と一致しました。SNRの開始・GC・終了・配列交換・消去、NoSの空レジストリや言語フォールバックなどを含みます。実際のNoS試合でもスキーマ20261103のレイアウト・パレット・役職を照合し、SNRの実ロビーでもレイアウトを照合しました。

実デバイスでは、起動時のWASAPI不連続通知を致命的切断として扱っていた問題を修正し、NoSとRust UIで75秒間の接続・音声入出力継続を確認しました。最終比較では別途、実ゲームと通話相手1接続を使用します。

全役職・全端末の動作保証や画面のピクセル一致を意味しません。TOH4E実試合はゲーム側のロビー作成エラーで未確認です。実32bitゲーム、複数人のインターネット通話、Bluetooth、デバイス抜き差し、スリープ復帰、長時間通話は追加確認が必要です。バーサーカーなどのDSP波形はWeb Audioと完全一致ではありません。問い合わせなどの外部更新はローカル検証を中心にし、本番投稿・本番更新インストールは行っていません。Linux／macOSは配布対象外です。

## ビルド

Node.js24、Rust MSVC、Visual Studio C++ Build Tools、WebView2 Runtimeが必要です。Rustターゲットは `wasm32-unknown-unknown` と `i686-pc-windows-msvc`、wasm-bindgen-cliはCargo.lockに対応する0.2.130を使用します。.NET SDKは旧実装との比較テストにのみ必要です。

```powershell
npm ci
rustup target add wasm32-unknown-unknown i686-pc-windows-msvc
cargo install wasm-bindgen-cli --version 0.2.130 --locked
$env:CARGO_INCREMENTAL='0'
$env:CARGO_BUILD_JOBS='2'
npm run verify:tauri-base
cargo test --manifest-path src-tauri/Cargo.toml --workspace --bins --lib
npm run tauri:build
node scripts/verify-rust-package.mjs
```

既存の依存ライブラリ・ビルドキャッシュを再利用し、別ディレクトリへのコピーは不要です。フロントエンドのビルド完了後にアプリをビルドします。`npm run tauri:build` は別名のインストーラーとポータブルフォルダーを作り、公開しません。保持済みの配布バージョンは再梱包せず、新しいベータ番号を使います。配布物監査スクリプトでは7-ZipのCLIも使用します。

最終メモリ比較は `memory-comparison-rust-ui-3.2.62.json`、配布物監査は `validation-rust-package-3.2.62.json`、実装の追跡は `rust-migration-status.json` を参照してください。β7の過去測定は `memory-comparison-final-3.2.62.json` に保持しています。

## 最終メモリ比較（2026-11-07）

The Skeldの実ゲーム5人・試合中、聴取範囲内の通話相手1接続、既定マイク／スピーカー、出力音量0、AEC／NS／AGC有効、オーバーレイOFF。各100秒の2回測定で60〜90秒の中央値を比較しました。相手音声は同一PC内で生成し、音声は保存していません。ゲーム本体・検証サーバー・相手役を除き、アプリの全子プロセスを合計しています。

| 版 | 専用物理メモリ | 専用コミット |
|---|---:|---:|
| Electron 3.2.62 | 166.4 MiB | 295.3 MiB |
| Tauri β8・画面表示 | 120.1 MiB | 216.8 MiB |
| .NET β1（参考） | 75.4 MiB | 119.5 MiB |
| Tauri β8・画面を閉じた状態 | 16.0 MiB | 19.7 MiB |

画面表示中のTauriはElectronより専用物理メモリが約46.4 MiB（27.9%）少ない結果でした。UIをRustに移しても、表示に使うWebView2のプロセスは残ります。画面を閉じるとその分を解放します。

.NETには再生バッファ警告と復号音声量の差があり、同等の音声動作を確認できた比較値ではありません。参考値として記載しています。これは短時間の同条件比較で、長期リークや全Mod・全役職の使用量を保証しません。詳細はmemory-comparison-rust-ui-3.2.62.jsonを参照してください。
