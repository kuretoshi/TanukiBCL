# タヌキのベタクル Tauri 3.2.71 ベータ3

他プレイヤーの受信の揺らぎを、RTPクロック単位から秒へ換算してからミリ秒にします。固定しているrtc 0.21.1は、生成したRTCP Receiver Reportのjitterをクロック単位のまま統計へ渡すため、アプリ側の統計アダプターで補正します。コーデック情報がある場合はそのclockRateを使い、情報が省略されたOpusでは48kHzを使います。48kHzで480クロックは10msです。ツールチップはElectronと同じ整数丸めに揃えます。

オーバーレイはElectronのDOM構造と `--size`（75 / 表示人数 vh）を使い、左右の名前欄、丸いキャンバス、衣装のオフセット、発話・ベント時の表示とゼロ人時の非表示を揃えています。ゲームのクライアント領域に追従し、タイトルバーのずれを除きます。診断モードでは追従ウィンドウを表示しません。

通常版3.2.71を基準とし、β1のSNR衣装とβ2のホスト設定待機の修正を保持しています。既存の依存・Cargoターゲット・音声リソースを再利用し、Rust UIのビルド後に `npm exec -- tauri build --features custom-protocol` で生成してください。`frontendDist` は `../out/tauri-rust-ui` の相対ディレクトリを維持します。追加配布はWindows x64向けインストーラーのみです。Electron版と以前のベータ版を保持し、共有音声モデルの再導入は不要です。

検証記録は `validation-receive-jitter-3.2.71-beta3.json` と `validation-rust-package-3.2.71-beta3.json` を参照してください。Rust回帰テスト、Electron実装による基準値、配布用実行ファイルの非表示での起動・待機復帰・設定操作とローカルの合成音声の受信統計を確認します。マウス・キーボード・入力フォーカス、物理マイク・スピーカーを使いません。実試合・多人数のインターネット通話、インストーラーの実行は今回の検証に含みません。

`node scripts/test-tauri-overlay-parity.mjs` はビルド済みRust/Wasmと、固定したElectronのAvatarOverlay・Avatarコンポーネントを非表示の画面で描画します。ローカルの合成IPCと画像を使い、左右・簡易・上下・非表示、1/13/20人、表示対象ゼロ、NoS衣装の11通りで座標・サイズ・名前・枠色を比較します。配置比較中はCSSトランジションを無効化し、許容差は1.1pxです。ウィンドウは一度も表示しません。
