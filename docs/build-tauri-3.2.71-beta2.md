# タヌキのベタクル Tauri 3.2.71 ベータ2

ホスト側がベタクルを起動していない場合など、通話設定の未受信を正常な待機状態として扱います。赤いERROR画面でプレイヤー一覧を隠さず、「ホスト側でもベタクルを起動してください」と案内します。ホスト設定を受信すると案内を解除します。設定受信前の送信・音声経路の制限と、実際の接続・音声エラーの表示は維持します。

通常版3.2.71を基準とし、ベータ1のSNR衣装修正を保持しています。既存のNode.js依存ライブラリ・Cargoターゲット・音声リソースを再利用し、Rust UIを先にビルドして `npm exec -- tauri build --features custom-protocol` で生成してください。`frontendDist` は `../out/tauri-rust-ui` の相対ディレクトリを使います。追加配布はWindows x64向けインストーラーのみです。Electron版とベータ1は保持し、共有音声モデルの再導入は不要です。

検証記録は `validation-host-settings-wait-3.2.71-beta2.json` と `validation-rust-package-3.2.71-beta2.json` を参照してください。Rustテストに加え、配布用実行ファイルを非表示で起動し、ホスト不在時の案内・一覧・送信抑止、設定画面の開閉、認証されたホスト設定の受信後の復帰をローカルの合成データで確認します。マウス・キーボード・入力フォーカスは使用しません。実試合・物理マイク・多人数通話やインストーラーの実行は今回の検証に含みません。
