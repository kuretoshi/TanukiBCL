ボイスストーンの音声認識に、Silero VAD＋SenseVoiceの共有ローカルモデルを追加しました。音声認識APIへの登録や音声送信は不要です。

- 初回は各版の詳細設定にある「共有モデルをダウンロード」から共通インストーラーを実行し、ベタクルを再起動してください。各版でモデルを共用し、準備済みなら通常は共有モデルを使用します。未準備・オフの場合は従来のVoskを使用します。
- タヌキ丼未検出時は認識モデルを読み込みません。連携終了時には録音・認識を停止し、古い認識要求や音声効果が残らないようにしています。3.2.68の通話安定性に関する修正も含みます。
- 設定された録音時間の終了後に認識し、結果を確認して設置・再録音・取消できます。変身・NGワードの認識方式は従来どおりです。

タヌキ丼はβ24へ更新してください。通常版・Lite版は3.2.69、Tauri版は3.2.69-tauri-beta.1、.NET版は3.2.69-net-beta.1です。Web・モバイル版は3.67です。Web・モバイル参加者の認識はホストが担当します。

ビルド、合成音声による認識、未検出・検出解除・再検出と役職連携の自動テストを実施しています。物理マイクでの認識精度と多人数プレイ時の負荷は未確認です。
